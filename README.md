# comparacion-modelos-cancer-mama
La idea del proyecto: un modelo que da el riesgo en porcentaje y lo explica, en vez de solo una etiqueta. El dataset: de dónde sale, sus datos básicos, la licencia, la cita y cómo descargarlo. Metodología y resultados: la búsqueda de hiperparámetros, la comparación de los 4 modelos y las métricas en el set de prueba.
